What the Inspector preserves

The instrument is designed around claim fidelity rather than presentation alone. An OPEN result retains a concrete materiality witness. A selected inclusion minimal obligation set retains removal witnesses showing why each selected Proposition is necessary. A declared Route remains model relative unless the applicable source preservation evidence supports exporting it further.

Hosted copy and archival record

The hosted application serves the same five browser files from the frozen v0.5.0 release. The site does not add a hosted semantic backend. The Zenodo software record remains the archival software record, and the canonical repository contains the frozen source, validation records, evidence summaries, and verification tooling.

Claim boundary

The Inspector makes formal results and their qualifications easier to inspect. It does not turn model relative closure into source equivalence, does not establish P2 where P2 has not been tested, and does not enlarge the bounded commissioning claims reported in the Technical Note.
