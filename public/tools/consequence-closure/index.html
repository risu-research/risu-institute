Current surface and frozen record

Let the interface evolve without rewriting the published result.

The current hosted surface delegates semantic analysis to the exact frozen v0.5.0 engine and Core v0.1.0, but moves that computation into a Web Worker and adds a stronger interaction layer for challenge, comparison, progressive rendering, and inspection-record integrity checks. The frozen five-file v0.5.0 browser release remains separately available and byte-pinned.

This split is deliberate. The DOI-backed release remains a stable, reproducible research artifact while the current interface can improve without pretending that a later presentation layer was part of the archived release.
