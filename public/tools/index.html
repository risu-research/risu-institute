Same tool.
Different consequence.

An AI-facing tool can keep the same name and inputs while losing a safeguard that changes what the action actually does. RISU Verify checks whether that safeguard survived.

State the consequence that matters. Verify the projected action against it. Inspect exactly where the result holds, fails, or remains incomplete.

Why this exists

Interfaces can preserve appearance while changing meaning.

1 · Reviewed sourceA consequence is declared.

Example: update only the version that was actually reviewed. If it changed, reject the stale action.

→
2 · Agent-facing projectionThe operation crosses an interface.

The name, schema, and visible inputs can remain intact even when the decisive safeguard is weakened or lost.

→
3 · RISU VerifyCheck consequences, not appearances.

Compare the declared source consequence with what the projection actually produces across bounded situations.

Why it matters: an agent may appear to use the same tool while the action no longer respects the condition a human, policy, or upstream system relied on.

What you get

Three outcomes. Explicit evidence. No mystery score.

✓

Safeguard preserved

The declared consequence is realized and the material distinction still governs the effect within the stated scope.

×

Safeguard lost

At least one admitted situation reaches the wrong consequence, or the necessary distinction does not govern the effect.

?

Not enough assurance

The current evidence or declared model does not justify either preservation or contradiction.

Evidence and reproducibility

Simple on the surface. Inspectable underneath.

The current release retains GitHub and Azure calibration cases, a real historical GitHub regression-to-repair transition, audit-hardened provenance, a development Version-Bound Effect profile, and a prospectively sealed Corpus 0.1 protocol.

The historical transition is retrospective validation, not an independent bug-discovery claim. The VBE profile is calibrated on retained cases; prospective generalization is reserved for Corpus 0.1. RISU Verify provides bounded, model-relative assurance rather than whole-system safety.
