Flagship assurance software · v0.4.0-rc1 research release

Consequence assurance
for machine action.

A tool can keep the same name, inputs, and shape while losing a safeguard that changes what an action actually does. RISU Verify checks whether that consequence-defining safeguard survived the projection.

The result is not just a pass or fail. RISU carries the declared source consequence, bounded evidence, proof-carrying certificate, run identity, and browser-checkable handoff as one assurance record.

The gap RISU checks

Surface compatibility is not consequence preservation.

Ordinary interface checks can tell you that a tool still exists and that its schema still matches. RISU asks the next question: does the distinction that was supposed to control the effect still control it?

Interface layerSame action name · same parameters · same response shape
Operational layerThe safeguard may still have moved, disappeared, or stopped gating the effect.

Compare assurance records

See exactly what changed.

Open one .risu-compare.json, or select two .risu.json run records. RISU only labels the comparison “same declared source semantics” when both records carry the identical source semantic digest.

Scientific boundary
