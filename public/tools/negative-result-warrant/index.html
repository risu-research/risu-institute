Method

A consumer port with frozen reference points.

The local core ports the canonical Algolia normalizer, obligation evaluator, proposition derivation, composition, bound-evidence decoder, canonical real-source decoder, and exact premise gate. Browser Web Crypto replaces Node’s crypto implementation without changing digest inputs.

The canonical warrant, bound evidence, and Algolia real-source evidence remain exact canonical structures. The versioned portable envelope is Inspector-specific and carries the supplied body text required to reproduce bindings after JSON import.

Receiver validation is not serialized authority. Imported evidence must be reconstructed and validated again. User-supplied capture integrity is not provider authentication.
