FROZEN RESEARCH RELEASE · LOCAL-FIRST · 2026

Inspect the evidence behind the relying decision.

What evidence, assumptions, identities, and derivations support a claim-specific relying decision?

Reliance Inspector supports recorded and counterfactual canonical cases, local verification of compatible self-auditing evidence bundles, inspection of boundary basis and derivation provenance, and evaluation of already-verified semantic objects using the frozen Python consumer. It can export deterministic evaluation records. The browser interface is presentation and control surface only; semantic applicability remains in the frozen local consumer.

Boundaries

Reliance Inspector does not discover every adverse path, establish issuer or signature authenticity, authorize actions, reserve resources, guarantee commit, mutate providers, or implement semantic verdict logic in browser JavaScript. Those limits are part of the frozen release boundary.

The instrument is distributed as a local-first release. This page provides its archival record, source repository, and technical note; semantic evaluation runs in the local release.
