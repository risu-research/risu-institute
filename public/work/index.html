Research program

Semantic integrity across protocol boundaries.

RISU develops bounded, inspectable artifacts around three ways machine-readable meaning can break across connected systems: a shared semantic identity may be missing, translation may introduce unsupported meaning, or translation may silently discard meaning already present. These labels organize the work; they do not expand the claim scope of any individual artifact.

INVENTED · Experimental profile · 2026

HTTP→MCP Method-Inference Soundness Profile

When HTTP operations become MCP tools, what machine claims can safely be inferred from the HTTP method alone?

This bounded executable profile tests whether method-derived MCP ToolAnnotations assert active guarantees unsupported by the source method semantics. Its frozen oracle covers GET, POST, PUT, PATCH, and DELETE across 40 conformance states.

LOST · Experimental profile · 2026

OpenAPI→MCP Problem-Semantics Preservation Profile

When an OpenAPI-described API already exposes RFC 9457 Problem Details, does OpenAPI→MCP translation keep that meaning machine-addressable?

Under the frozen 12-case profile, three tested translation architectures each classified 11 in-scope cases as LOSS. A constructive translation over the tested MCP 2026-07-28 carrier capacity preserved all 11, showing that the observed loss is not forced by that tested carrier capacity.
