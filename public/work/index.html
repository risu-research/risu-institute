Semantic preservation · experimental profile

OpenAPI→MCP Problem-Semantics Preservation Profile

An API can describe errors using RFC 9457 Problem Details. Translation into MCP may lose their machine-readable meaning.

Three tested translation architectures lost meaning in all 11 in-scope cases; a constructive translation preserved all 11 within the tested profile.
