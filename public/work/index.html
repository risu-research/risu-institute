Research program

Semantic integrity from interface to action.

RISU develops bounded, inspectable artifacts around failure modes that appear when automated systems expose, translate, compose, rely on, or retire machine-readable state. The program currently studies missing semantic identity, unsupported semantic gain, silent semantic loss, insufficiently warranted negative premises, cross-boundary strengthening of evidentiary status, and operational consequences that survive agent retirement.

OpenAPI→MCP Problem-Semantics Preservation Profile

Under the frozen 12-case profile, three tested translation architectures each classified 11 in-scope cases as LOSS. A constructive translation over the tested MCP 2026-07-28 carrier capacity preserved all 11, showing that the observed loss is not forced by that tested carrier capacity.

UNWARRANTED · Experimental executable reference profile · 2026

Negative Result Warrant

When a bounded query returns zero, what evidence is sufficient for a downstream operation to use that exact negative premise?

The profile makes a bounded negative query premise usable only after provider-reported evidence is sufficient, bound to the exact proposition, transported, and receiver-validated. Its recorded Algolia contrast distinguishes an ordinary zero-result observation that remains UNKNOWN from a separate verification observation that becomes WARRANTED_ZERO.

LAUNDERED · Experimental conformance system · 2026

ClosureProbe

Where does a query-relative negative conclusion first become stronger than the evidence that crossed the boundary?

ClosureProbe is a receiver-anchored executable conformance system for negative-evidence integrity across observable agentic toolchains. It reconstructs root evidence from supplied source material, binds source context and the exact negative proposition, propagates evidence anchoring through the trace, and localizes the earliest unsupported strengthening, substitution, scope drift, or profile change. It does not decide whether nothing exists; it tests whether the supplied evidence still justified saying so after the observed boundaries.

UNRESOLVED · Deterministic verifier · 2026

Bounded Agent Closure

After an autonomous agent is disabled, what proves that the consequences attributable to it have actually reached a terminal, stable state?

Bounded Agent Closure distinguishes administrative retirement from operational closure. Under the explicit RISU_AGENT_CLOSURE_V0 evidence profile, its deterministic verifier follows evidence-backed residual consequences transitively from the retiring root, evaluates postconditions across authority, execution, commitments, and operational state, and requires stable convergence before issuing the bounded claim CLOSED.
