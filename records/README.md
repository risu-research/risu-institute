# RISU Institutional Experimental Records

This directory contains frozen research checkpoints that are useful enough to preserve and cite internally or publicly, but are not numbered RISU Technical Notes and are not necessarily standalone software releases.

Each record should:

- state a narrow research question and supported claim;
- preserve exact execution and artifact identities;
- keep failed or negative controls as part of the record when scientifically relevant;
- separate raw archival evidence from curated public interpretation;
- avoid silently widening claims after a result is known;
- use machine-readable result metadata where practical.

Only `public/` is deployed as the RISU Institute website. Files under `records/` are repository records, not website assets.
