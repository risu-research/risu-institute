# G25D follow-on: end-to-end AXI-to-pin data, declared before exploring serial timing, 2026-09-20

After G25A/B/C prove the original AXI proof omits physical serial and a fixed mid-frame reset can leave start bit low, those observations alone are largely source-obvious. A qualitatively distinct question is whether a formal obligation over the **unaltered non-FORMAL physical entire UART** can establish correspondence between an AXI byte write and eight serial bits for *every* possible byte, under an explicit, bounded fixed schedule and a documented baud. This would add a functional end-to-end transfer relation not covered by stock AXI-lite protocol verification; it would NOT be a new UART algorithm or historical defect.

Original commit d8ea86d1b8ef47d0b1c13f291a958b6aac9229f9 unchanged. Use `INITIAL_SETUP=4` (4 clocks/baud), no hardware CTS, default 8N1, one AXI write at 0xC with low-byte strobe, arbitrary immutable 8-bit data value; reset deasserted before write, no midframe reset. Stage 1: native original RTL trace for 0xA5 to determine start/data sample timing and detect duplicate transactions; preserve this exploratory trace. Stage 2: after fixing sample schedule based on trace and source UART specification, pin sample checkpoints in *new property harness* before solving; check bounded universal assertions that all eight pin bits equal bus-byte bits for all 256 byte values. Add separately reachable cover of a full data frame and controls for no AXI duplicate write. Archive full source hashes, raw status, actual model trace. A fixed-program bounded proof is NOT proof of arbitrary bus timing, parity modes, baud rates, RX, analog pin or full CPU. If the result does not clearly exceed ordinary source inspection and one/two directed simulations in the particular decision it establishes, leave G23 unchanged. Report any failed exploratory harnesses and diagnostic corrections.
